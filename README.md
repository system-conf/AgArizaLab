# Ağ Arıza Laboratuvarı

Tarayıcıda oynanan, Türkçe, açık kaynaklı bir **ağ sorun giderme oyunu**. Bir restoran, ofis
veya mağazanın küçük ağı bozulmuştur; cihazlara tıklar, ayarlarını okur, `ping`, `ipconfig`,
`nslookup` gibi komutları çalıştırır, arızayı bulup düzeltirsin.

Türkçe ağ öğrenme araçlarındaki boşluktan ilham alınarak hazırlandı.

## Çalıştırma

```bash
npm install
npm run dev
```

Testler için:

```bash
npm test
```
